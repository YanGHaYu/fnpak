访问口令

服务端启用了会话校验。--host 0.0.0.0 启动时口令来自 --access-token 或环境变量 PIKO_SERVER_TOKEN；本机启动时见控制台打印的那一行，也已写入数据目录的 access-token 文件。

这道门只挡同网段随手打开页面的人；对外暴露请交给 fnOS 反向代理 + 强口令。

账号登录

用 PikPak 账号的邮箱与密码登录。密码只随本次请求转发给 PikPak，既不会写进页面，也不会进服务端日志。 登录成功后会话写入数据目录，重启服务仍保持登录。

或导入令牌

在已登录的 Piko 桌面客户端里取得 accessToken 与 refreshToken，粘贴到这里；服务端会把会话写进 piko.home，后续由 SDK 自动刷新。
